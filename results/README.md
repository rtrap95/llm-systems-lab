# Results

Store compact, reviewable experiment outputs here, grouped by experiment ID. A useful result bundle contains:

- `measurements.csv` with units and a header;
- `environment.json` with device and relevant software versions;
- a short `summary.md` or a link to the experiment report;
- plots only when they clarify the comparison.

Keep the detailed hypothesis and interpretation in `experiments/<id>-<slug>/README.md`. Do not commit model weights, raw datasets, or large profiler captures; see `.gitignore` for local-only artifact patterns.
